# Cosmic Port — Engine Wave 1a (expression functions + multi-ability enchants) Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Land the two compiler-side wave-1 primitives — `EXPR_PARAMS` (min/max/
clamp/floor/rand in the expression grammar) and `MULTI_ABILITY_ENCHANT` (several
ability blocks per enchant level) — as PR 2a, the first of four wave-1 engine PRs.

**Architecture:** Both items extend existing machinery, no new subsystems:
expression functions are new tokens/productions in `schema.grammar.expr` lowered
to new `NumExpr` nodes evaluated in `engine.condition.NumExprEval`; multi-ability
is an `EnchantDefReader` schema extension that fans one level block into N
`AbilityDef`s — the erase stage already flattens arbitrarily many `AbilityDef`s
per source (that IS the architecture). Expression-valued numeric params already
ship (`"%ragestacks% * 1.5"` precedent); this widens what the expressions can say.

**Tech Stack:** pure-JDK `se-schema`/`se-compile` modules, `se-engine` evaluator,
JUnit, the fuzz corpora, `regenDocs` goldens.
