# Deviation ledger

Every divergence between measured cosmic-jar behavior and what StarEnchants ships
(spec §6, ruling R2). Display strings never deviate.

Ids are `D-<doc>-<n>`, keyed to the matrix doc that owns the entry
(`matrix/01-…` → `D-01-nn`, `matrix/12-…` → `D-12-n`); `D-001` is the one
corpus-wide row.
